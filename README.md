# 2D Platformer Game

## 🚀 Cara Menjalankan Proyek

### Prasyarat

Unduh dan pasang [Godot Engine (v4.x)](https://godotengine.org/download) terlebih dahulu.

### Langkah-langkah

1. **Kloning Repositori**
   Buka terminal/command prompt dan jalankan:
   ```bash
   git clone [https://github.com/ferdism/platformer-game.git](https://github.com/ferdism/platformer-game.git)
   ```
2. Import Proyek ke Godot
   - Buka aplikasi Godot Engine.
   - Di halaman Project Manager, klik tombol Import di sisi kanan.
   - Pilih Browse, lalu arahkan ke folder hasil kloning dan pilih file project.godot.
   - Klik Import & Edit.

   Jalankan Game
   - Tekan tombol F5 pada keyboard (atau tombol Play di pojok kanan atas editor Godot) untuk langsung memainkan game.
